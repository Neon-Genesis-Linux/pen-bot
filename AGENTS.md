# AGENTS.md

Three documents govern work in this repository. Read all three before
contributing.

- [AI_POLICY.md](AI_POLICY.md) covers AI and LLM assisted contributions: what
  needs disclosing, who is responsible for a submission, and what maintainers
  may ask for. It applies whether or not a tool was used.
- [CONTRIBUTING.md](CONTRIBUTING.md) covers the mechanics of a contribution:
  what to read before editing, which checks to run and report, and commit
  message format.
- [DOCUMENTATION.md](DOCUMENTATION.md) says where each kind of documentation
  belongs, including the Go doc comment rules that CI does not check.

This file is a pointer, deliberately. It carries no rules of its own, so there
is nothing here that can drift from the documents it points at.
